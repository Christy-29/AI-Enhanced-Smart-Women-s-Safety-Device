# AI-Enhanced Smart Women's Safety Device Using IoT

## 📌 Project Overview

The **AI-Enhanced Smart Women's Safety Device Using IoT** is a smart wearable safety solution designed to enhance women's personal security. The system combines IoT technology with intelligent emergency detection to provide immediate assistance during critical situations.

The device continuously monitors the user's safety through an SOS button and an MPU6050 accelerometer sensor. When an emergency is detected, the ESP32 microcontroller retrieves the user's live GPS location and sends an alert to registered emergency contacts through Wi-Fi and a cloud platform. A buzzer is also activated to attract nearby attention.

## ⚙️ System Workflow

1. ESP32 initializes all connected modules.
2. The system continuously monitors the SOS button and MPU6050 sensor.
3. An emergency is detected either by pressing the SOS button or through abnormal movement detection.
4. The GPS module retrieves the user's current location.
5. The ESP32 sends the emergency alert via Wi-Fi to the cloud platform.
6. The cloud updates the mobile application and notifies emergency contacts.
7. The buzzer activates to alert nearby people.
