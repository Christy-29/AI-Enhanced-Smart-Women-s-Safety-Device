# AI-Enhanced Smart Women's Safety Device Using IoT

## 📖 Project Overview

The AI-Enhanced Smart Women's Safety Device Using IoT is a smart safety solution designed to improve women's personal security. The project demonstrates how IoT technology can be used to trigger emergency alerts through an ESP32-based system.

A prototype was developed using the Wokwi simulator to demonstrate the emergency alert mechanism. When the SOS button is pressed, the ESP32 activates a buzzer and LED to simulate an emergency notification.

## ⚙️ Working Methodology

1. ESP32 initializes the connected components.
2. The system continuously monitors the SOS button.
3. When the button is pressed, an emergency is detected.
4. The LED turns ON.
5. The buzzer sounds to indicate an emergency.
6. The system demonstrates the emergency alert mechanism.
